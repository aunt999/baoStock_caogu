# 股票量化分析系统 GUI v3.0

## 功能特点

- 输入股票代码或名称进行搜索（支持200+股票名称映射）
- **K线图 + 成交量 + RSI + MACD + KDJ 五图联动**
- **同步十字光标**：移动鼠标，所有子图同步显示垂直线
- **KDJ指标图**：位于MACD下方，五图联动
- **买卖点消息提示**：分析完成后自动弹出信号提醒
- **回测功能面板**：显示初始资金、最终资产、收益率、胜率等
- 自动计算技术指标：MA5/10/20/60, RSI, MACD, KDJ, 布林带
- 买卖信号自动标记在K线图上（▲买入 ▼卖出）
- 右侧实时显示当前指标和信号
- 支持时间范围选择（3个月/6个月/1年/2年）

## 使用说明

1. 输入股票代码（如 002285）或名称（如 世联行）
2. 选择时间范围（默认6个月）
3. 点击"分析"按钮
4. **鼠标移动到任意图表上**：所有子图同步显示垂直光标线
5. 查看K线图上的买卖信号标记（▲买入 ▼卖出）
6. 如有买卖信号，会自动弹出消息提示窗口
7. 右侧显示回测结果、当前指标和交易建议

## 信号规则

**买入信号:**
- MA5金叉MA10且价格在MA20之上
- RSI < 30 超卖
- KDJ超卖 (K<20, J<0)
- MACD低位金叉

**卖出信号:**
- MA5死叉MA10
- RSI > 70 超买
- KDJ超买 (K>85, J>95)
- MACD高位死叉
